CYBER is a beautifully constructed, responsive cyberpunk-themed landing page and resource hub. It offers users immediate recommendations for mechanical engineering, programming, and robotics, and gathers user feedback via an interactive contact block.

---

## ⚡ Design Philosophy & Features

- **Cyberpunk UI**: Minimalist, dark-neon theme with customized buttons, clean borders, and glassmorphic card effects.
- **Academic Directory**: Curated linkages to video lecture collections spanning Python Programming, Web Development, Mechanical Design, and Robotics.
- **Client Side Validation**: Structured interactive feedback contact forms containing client validation check states.
- **Iconic Branding**: Integrated custom-designed graphics and icons.
